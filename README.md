موقع محمد أحمد سوغو الوداني

الملفات:
- index.html: الصفحة الرئيسية.
- profile.jpeg: صورتك الشخصية.
- articles.json: قائمة المقالات.
- article.html: صفحة قراءة المقال.
- add-article.html: أداة إنشاء المقالات.

إضافة مقال:
1. افتح add-article.html من رابط موقعك بعد نشره.
2. اكتب العنوان والتصنيف والملخص ونص المقال، ثم نزّل articles.json.
3. ارفع الملف الجديد إلى مستودع GitHub لاستبدال الملف السابق.
4. انتظر تحديث الموقع.

النشر: أنشئ مستودعًا عامًا في GitHub، وارفع جميع الملفات إلى الجذر، ثم Settings > Pages > Deploy from a branch > main > /(root) > Save. تفاصيل رسمية: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

الموقع سيكون عامًا؛ لا تنشر بيانات لا تريد إتاحتها للناس.


## طريقتا إضافة المقالات
راجع `ADMIN_SETUP.md` لتفاصيل لوحة الإدارة والطريقة الاحتياطية. `admin/config.yml` يحتاج تعديل اسم مستخدم ومستودع GitHub وإعداد OAuth قبل النشر المباشر.

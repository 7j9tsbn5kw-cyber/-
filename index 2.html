مرحبًا بك في لوحة إدارة الموقع

اختر الطريقة المناسبة لإضافة مقالاتك. يمكنك الاحتفاظ بالطريقتين معًا:

الطريقة الأولى: النشر من لوحة الإدارة

اضغط الزر التالي لفتح نظام إدارة المحتوى. بعد إعداد ربط GitHub وتسجيل الدخول، تستطيع إنشاء المقالات ونشرها من المتصفح.

فتح لوحة إدارة المحتوى

ملاحظة إعداد مهمة: النشر المباشر عبر GitHub يحتاج إلى تهيئة موفر تسجيل دخول OAuth وربطه بموقعك المنشور. ملف الإعداد موجود في config.yml، لكن بيانات OAuth لا يمكن إنشاؤها نيابة عنك دون حسابك وصلاحياته.

الطريقة الثانية: تجهيز المقال يدويًا

إذا لم تعمل لوحة النشر المباشر أو أردت طريقة احتياطية، استخدم أداة إعداد المقالات، ثم ارفع ملف المقالات إلى GitHub.

فتح أداة إضافة المقالات الاحتياطية
للمحافظة على أمان الموقع: لا تضع كلمة مرور GitHub أو رموز الوصول السرية داخل ملفات الموقع. استخدم تسجيل الدخول الآمن فقط.
